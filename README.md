# FIGR

FIGR je desktopová aplikace pro osobní finance a investiční přehled.

## Lokální spuštění

```sh
npm install
npm run dev
```

Desktopová verze:

```sh
npm run desktop:dev
```

Produkční lokální build:

```sh
npm run desktop
```

## Technologie

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- Electron
- SQLite
